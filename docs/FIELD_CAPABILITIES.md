# 字段能力边界

本文档说明 Chat Agent 和条件筛选接口当前可以安全执行的字段范围。原则是：只有已经落入本地数据库、可由后端 schema 校验并能被 SQL 查询执行的字段才允许筛选；缺少数据来源或口径不稳定的字段必须明确说明不支持，不能改写成近似指标后返回部分满足结果。

## 字段能力表

| 字段名 | 是否支持 | 数据来源 | 更新频率 | 缺失行为 | 典型中文表达 | 不支持原因 |
|---|---:|---|---|---|---|---|
| `pe` | 是 | `stock_daily.pe` | 交易日行情 / 估值同步 | 该条件不会命中缺失值 | PE、市盈率、低估值 | - |
| `pb` | 是 | `stock_daily.pb` | 交易日行情 / 估值同步 | 该条件不会命中缺失值 | PB、市净率、破净 | - |
| `market_cap` | 是 | `stock_daily.market_cap` | 交易日估值同步 | 该条件不会命中缺失值 | 市值、大盘、中盘、小盘 | - |
| `dividend_yield` | 是 | `stock_daily.dividend_yield`，由 `stock_dividend` 本地重算 | 分红同步 / 估值补全后刷新 | 缺失不按 0 处理 | 高分红、高股息、股息率 | - |
| `close` | 是 | `stock_daily.close` | 交易日行情同步 | 该条件不会命中缺失值 | 股价、收盘价 | - |
| `turnover` | 是 | `stock_daily.turnover` | 交易日行情同步 | 该条件不会命中缺失值 | 换手率、活跃度 | - |
| `roe` | 是 | `stock_financial.roe` | 周度财务指标同步 | 该条件不会命中缺失值 | ROE、净资产收益率 | - |
| `revenue_yoy` | 是 | `stock_financial.revenue_yoy` | 周度财务指标同步 | 该条件不会命中缺失值 | 营收同比、收入增长 | - |
| `profit_yoy` | 是 | `stock_financial.profit_yoy` | 周度财务指标同步 | 该条件不会命中缺失值 | 净利润同比、净利增长、利润正增长 | - |
| `gross_margin` | 是 | `stock_financial.gross_margin` | 周度财务指标同步 | 该条件不会命中缺失值 | 毛利率 | - |
| `debt_ratio` | 是 | `stock_financial.debt_ratio` | 周度财务指标同步 | 该条件不会命中缺失值 | 负债率、资产负债率 | - |
| `industry` | 是 | `stock_basic.industry` | 股票列表 / 财务同步 | 支持部分中文行业词模糊匹配 | 银行、消费、医药、科技 | - |
| `market` | 是 | `stock_basic.market` | 股票列表同步 | 需要匹配本地板块文本 | 主板、创业板、科创板、北交所 | - |
| `profit_cagr_3y` | 否 | 未入库 | 暂无同步任务 | ask_clarification / 明确说明不支持，不筛选 | 三年净利润复合增速、CAGR、复合增速 | 当前只保存最新报告期同比，缺少连续年度可比口径和年度序列计算 |
| `deducted_profit` | 否 | 未入库 | 暂无同步任务 | 明确说明不支持，不筛选 | 扣非净利润、扣非净利 | 本地 `stock_financial` 未保存扣非口径 |
| `operating_cash_flow` | 否 | 未入库 | 暂无同步任务 | 明确说明不支持，不筛选 | 经营现金流、现金流 | 本地未保存现金流量表字段 |
| `eps` | 否 | 未入库 | 暂无同步任务 | 明确说明不支持，不筛选 | EPS、每股收益 | 本地没有每股收益口径，也未处理摊薄/基本 EPS 差异 |
| `ps` | 否 | 未入库 | 暂无同步任务 | 明确说明不支持，不筛选 | PS、市销率 | 本地没有市销率字段；不能用市值/最新营收临时替代 |
| `institution_holding` | 否 | 未入库 | 暂无同步任务 | 明确说明不支持，不筛选 | 机构持仓、基金持仓、北向资金 | 本地未同步持仓和资金流数据 |
| `research_rating` | 否 | 未入库 | 暂无同步任务 | 明确说明不支持，不筛选 | 研报评级、目标价 | 本地未同步研报数据，且评级口径差异大 |

后续若要支持暂不支持字段，需要先新增可靠数据表、同步来源、报告期或 TTM 口径校验，再把字段加入后端 schema 白名单和测试评测集。

## Agent 执行规则

- 支持字段内的组合条件先走本地确定性解析，不等待 Qwen；例如 `ROE 大于 15 且最新季度净利润同比正增长的成长股` 会生成 `roe > 15` 与 `profit_yoy > 0` 等结构化条件，并保留 `model_ms=0` / `fallback_reason=local_fast_path`。
- 低估值、高分红、成长股、稳健、银行股、消费股等模糊词只能补充已支持字段；明确数值条件优先，模糊兜底不能覆盖用户写出的阈值。
- 如果同一句话同时包含支持字段和不支持字段，Agent 必须在 AI health / Qwen / screener 之前停止筛选并解释不支持字段，不能返回“只满足支持字段”的部分结果。
- `stock_detail` 只定位详情，不触发筛选；解释、排序和分页必须依赖上一轮结果上下文。
- 普通自动化测试使用 fake model，不依赖真实 AI；真实 Qwen/OpenCode Go 只在手动 smoke 中验证。
