## 1. 项目概述

`qwen-screener-main` 是一套 **FastAPI 后端 + Vue 3 前端** 的 A 股数据管理与分析 Web 系统，通过 **AKShare** 采集行情与财务数据，集成大模型实现自然语言选股与基本面分析。技术栈包括 SQLite/MySQL、Redis（可选）、APScheduler 定时任务、Docker Compose 部署等。

**免责声明**：本项目仅用于学习与研究，不构成任何投资建议。

## 3. 「Windows 窗口应用」说明

课题中的 **「Windows 窗口应用」** 在本对照中按以下理解评估（非 WinForms/WPF 图形桌面）：

- **满足条件**：可在 Windows 的 CMD、PowerShell 或 IDE 集成终端（黑窗口）中运行的程序。
- **本项目对应入口**：

```bash
cd backend

# 数据同步（终端输出同步进度）
python -m scripts.sync_data full

# 启动后端 API 服务
uvicorn app.main:app --reload --port 8000

# 运行测试
pytest tests/ -v
```

- **展示与分类**：主要依赖 **浏览器 Web 前端**（Dashboard、因子筛选、个股详情等）；终端侧以数据同步日志与服务日志为主。

**答辩表述建议**：

> 系统采用「命令行 + Web」双层架构：黑窗口负责数据同步与服务启动；浏览器负责行情展示、分类筛选与自选管理，满足「至少具备可在 Windows 终端运行的程序」的要求。

## 4. 分项缺口详解

### 4.1 第 1 项 — 网络爬虫

| 子项 | 状态 | 说明 |
|------|------|------|
| 每日行情（OHLC、成交量、PE/PB 等） | ✅ | 新浪 / 东财 / 雪球多通路，`sync_data` 子命令 |
| 涨停 / 跌停数据 | ❌ | `docs/STATUS.md` 明确：AKShare 无涨跌停限价，Dashboard 未展示 |
| 自建网络爬虫 | ❌ | 使用 AKShare 库封装，非 Scrapy/Requests 爬页面 |

**建议补做**：接入 tushare 涨停跌停接口，或自建爬虫抓取 1～2 个公开页面；论文中可称「数据采集模块」并附爬虫代码章节。

---

### 4.2 第 2 项 — 数据处理

| 子项 | 状态 | 说明 |
|------|------|------|
| 多网站数据整合与格式统一 | ✅ | `backend/app/services/data_sync.py` |
| 按行业/板块/因子展示分类 | ✅ | 固定分类体系 + 筛选引擎 |
| 用户自定义分类标准 | ❌ | 无用户分组表与配置 UI |

**建议补做**：新增 `user_category`、`stock_category` 表，前端支持自定义分组与按组筛选。

---

### 4.3 第 3 项 — 数据库设计

| 表名 | 用途 |
|------|------|
| `stock_basic` | 股票代码、名称、行业、市场、上市日期等 |
| `stock_daily` | 日行情 + PE/PB/市值/换手率/股息率 |
| `stock_financial` | ROE、营收/净利同比、毛利率、负债率等 |
| `users` | 用户账号 |
| `watchlist` | 自选股、备注、预警规则 JSON |
| `chat_sessions` | 千问对话历史 |
| `notifications` | 预警通知 |
| `sync_meta` | 定时同步任务元数据 |

**结论**：满足「合理库表存储规整数据」要求，为当前完成度最高的模块之一。

### 4.5 第 5 项 — 智能提醒

| 预警类型 | 说明 |
|----------|------|
| `pct_up` | 自加入起累计涨幅 ≥ 阈值 % |
| `pct_down` | 自加入起累计跌幅 ≥ 阈值 % |
| `day_pct` | 日内涨跌 ≥ 阈值 %（对应课题「涨 5%」类需求） |
| `price_gt` / `price_lt` | 现价突破 / 跌破 |

实现位置：`frontend/src/services/alertEngine.js`、`frontend/src/components/AlertRuleEditor.vue`。

**局限**：30 秒轮询延迟；无操作系统级弹窗。

## 7. 运行环境与黑窗口启动步骤

### 7.1 环境要求

- Python 3.10+
- Node 20+（仅 Web 前端开发时需要）
- 可选：Docker、Redis、MySQL

### 7.2 首次数据同步（黑窗口）

```bash
cd backend
python -m venv .venv
.venv\Scripts\activate          # Windows PowerShell
pip install -r requirements.txt
cp .env.example .env              # 配置 AI Key（可选）
python -m scripts.sync_data full  # 约 5 分钟
```

### 7.3 启动后端（黑窗口）

```bash
uvicorn app.main:app --reload --port 8000
```

### 7.4 启动前端（新终端，浏览器访问）

```bash
cd frontend
npm install
npm run dev                       # http://localhost:5173
```

### 7.5 Docker 一键部署

```bash
cp backend/.env.example backend/.env
docker compose up -d --build
docker exec qwen-backend python -m scripts.sync_data full
# 浏览器访问 http://localhost:8080
```
